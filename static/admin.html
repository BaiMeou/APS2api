Anti-429 随机数注入
每次请求自动插入 100 位随机数，降低被缓存命中/限流的概率
Streaming
控制是否允许流式输出。
强制关闭流式输出
开启后所有请求都走非流式，等完整回复生成完再一次性返回。连接更稳定但响应延迟更高。
并行请求池
同时尝试多个节点，谁先成功就使用谁，明显降低坏节点造成的等待。
0 表示不限；超过限制的新下游请求会在会话池中保持 waiting，直到有活动会话结束。
说明：并行池大小只控制每个活动业务会话内同时运行的上游尝试数；Worker 端口范围用于订阅节点的本地 SOCKS 入口；最大补位轮次、首包总超时、活动业务会话上限填 0 表示不限。
